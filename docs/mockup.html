What changed in v2 and v3

  • Runs run side by side: each run gets its own herdr tab. Conductor opens a pane for each stage, closes it once the stage passes, and leaves it open if the stage fails or needs you.
  • Receipt is one key away: r works on every screen, there's a receipt column in the runs list, a receipt-so-far button while a run is working, and the receipt is also in the PR and on disk.
  • Agents control panes too: in tab 4, codex opened a cargo watch pane through conductor. It stays inside its own run's tab, and every pane it opens is recorded.
  • Less dense: larger text, fewer columns, a one-line explanation on each screen, and details folded away until you ask for them.
